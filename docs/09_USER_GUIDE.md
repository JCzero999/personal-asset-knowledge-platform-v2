# 新手使用手册

> **读者**：第一次使用这个平台的你，不需要懂代码。
> **适用版本**：2026-11-14（含作品「已实践」沉淀、AI 提炼与资产价值分级），本机部署地址 `http://localhost:3000`。
> 开发、部署与接口细节见 [README](../README.md) 与 [00_SCOPE.md](00_SCOPE.md) ~ [08_RUN_LOG.md](08_RUN_LOG.md)。

---

## 1. 这个平台用来做什么

一句话：**把收集到的资料沉淀成「资产」，把想法推进成「作品」，两者都能被检索、被图谱关联。**

它解决三个问题：

1. 资料散落各处，找不到、记不住 → 全部收进工作台，统一检索；
2. 想法停在收藏夹，没有推进 → 作品有四阶段，一眼看到卡在哪；
3. 内容之间没有联系 → 知识图谱把实体和关系抽出来，可以按关系浏览和提问。

### 两个核心概念

| 概念 | 是什么 | 有没有阶段 |
|------|--------|------------|
| **作品** | 要完成并交付的内容。比如一篇文章、一门课、一次咨询 | 有四阶段：草稿 → 已完成 → 已发布 → 已实践；**作品只在外库** |
| **资产** | 资料、笔记与参考，以及作品实践后沉淀下来的成果 | 没有推进阶段；内库资产带 S / A / B / C 价值等级 |

### 两个归属

| 归属 | 含义 | 放什么 |
|------|------|--------|
| **外库** | 收集的输入、还没走完实践的内容 | 全部作品；刚收集、还没验证的资产 |
| **内库** | 长期复用、已验证 | 只有资产，而且**必定带价值等级** |

> 归属看的是**可信程度**，不是内容从哪来。资产进内库只有两条路：AI 打分 ≥ 75 自动进，或 60–74 分时你在复核里点「通过」；内库资产也可以主动降到外库。作品不能手工搬进内库——它走完「已发布 → 已实践」时，系统会自动生成那条内库资产。

## 2. 第一次使用：5 分钟上手

### 第 1 步：登录

1. 打开 `http://localhost:3000`；
2. 点「登录」，跳到登录页；
3. 输入账号密码（首次使用先在 Logto 控制台创建账号），登录后自动进入工作台 `/workspace`。

> 登录页打不开或登录后报错，多半是 Logto 服务没启动。见第 5 节「打不开怎么办」。

**管理员不用单独登录**：管理员和普通用户是同一个登录页，只是登录后左侧栏「知识图谱」下面会多一项「系统管理」，进入 `/admin` 看后台（见 4.1）。没有这一项说明当前账号不在管理员名单里，找项目维护者把你的账号加进去即可，不能自助提权。

### 第 2 步：认识工作台

登录后看到的是工作台，从左到右四块：

- **最左图标栏**：工作台、内容检索、知识图谱，底部是账号与退出；
- **工作台目录**：按「浏览 / 归属 / 作品进程」分组，点条目改变列表范围；
- **内容列表**：当前范围下的条目，点一条，右侧直接打开详情；
- **右侧概览**：内容概览、作品进程、内容构成；选中条目后变成对象详情。

### 第 3 步：新建第一条内容

1. 点右上角「新建」；
2. 选类型：
   - **资产**：资料、笔记与参考；
   - **作品**：要完成并交付的内容，选完还要选**分类**。内置 7 种（文章 / 音视频脚本 / 课程 / 直播 / 咨询 / 外部笔记 / 未分类），可以自己加；面板里只出现「启用中」的分类；
3. 填**标题**（必填）；
4. 选**放在哪里**：作品固定在外库（选不了内库）；资产可以选内库或外库——**选内库时会当场跑一次五维评估**，所以建好就带 S / A / B / C 等级，不需要再手动评；
5. 「标签」选填：输入后按回车添加，最多 10 个；词表里没有的词会提示「＋ 创建标签」；
6. 「说明」选填，可以写来源、用途或下一步计划；
7. 点「创建」。

### 第 4 步：上传内容

1. 在工作台点内容标题，进入详情页；
2. 在「内容文件」区点「上传主内容」，选一个文件（25 MB 以内）；
3. 想挂补充材料就点「添加附件」，附件不限一个；
4. 上传后状态是「解析中」，通常几十秒内变成「已解析」。

> **主内容**用于检索；同类型再次上传会**替换**旧文件。**附件**会一直挂在对象下，不会被替换。

### 第 4 步补充：直接在页面里写正文

不想先写成本地文件再上传时，在详情页「内容文件」区点「**编写正文**」：

1. 先选**类型**：`Markdown`（默认）或 `纯文本`；打开已有的 `.md` 文件会自动切到 Markdown，其余按纯文本；
2. 纯文本模式左边是行号，右上角实时显示行数与字数；`Tab` 缩进两个空格，`Shift+Tab` 回退；
3. Markdown 模式左写右预览：`# 标题`、`**粗体**`、`- 列表`、`` `代码` ``、`> 引用`、`---` 分隔线都会立即显示成文章样式；**拖任一侧的滚动条，另一侧会跟着滚到同一位置**，长文对照不用手动找；当前文件按 `.md` 保存，检索与解析照常；
4. 写完按 `Ctrl+S`（Mac 上 `Cmd+S`）保存，等同「保存并上传」——内容会作为**主内容**写进内容库，旧主内容被替换，接着自动解析；
5. 已有可编辑文本内容（`.md` `.markdown` `.txt` `.json` `.csv`）时，按钮显示「**编辑正文**」，打开的是现有正文，改完保存同样是替换主内容。打开 `.md` 文件会自动切到 Markdown 类型，其余按纯文本。

> 有未保存改动时离开页面会弹确认，别习惯性点「离开」。只能编辑纯文本格式；PDF、Word 之类的文件仍需下载后改、再重新上传。

### 第 4 步补充：内容文件那一行的按钮

- **查看原文**：在新标签里看全文。文本类（`.md`、`.txt` 等）按纯文本直接显示，PDF 和图片内嵌预览——都是「看」，不是下载；
- **复制**：把全文放进剪贴板。浏览器不允许写剪贴板时会给出提示，这时点「查看原文」手动全选即可；用局域网地址（`http://192.168.x.x:3000`）访问时走的是兜底路径，同样可用；
- **下载**：真想存成文件时才用这个；
- 改正文统一走上方的「**编写正文 / 编辑正文**」，内容行里不再重复放一枚「编辑」。

> Markdown 类型支持常用语法；表格、脚注、内嵌 HTML 不渲染，会按原文显示。类型只决定编辑体验与保存的文件格式，内容本身始终以源码存入内容库。

### 第 5 步：检索

有两种入口：

- **首页搜索框**：输入 2 个字以上，200ms 后直接在下方列出前 8 条，标题里的关键词会标黄，显示所属库、分类与标签。↑↓ 选择、回车打开、Esc 关闭、⌘K / Ctrl+K 聚焦。它只做关键词匹配，所以很快。
- **内容检索页**（左侧「内容检索」）：完整结果，一个对象只出现一次，标注命中来自「关键词」「语义」还是两者。

检索会同时看两个地方：

1. **关键词**：标题、描述、分类名、标签名——输入几个字就能模糊匹配，不用和原文用词完全一致（全角 / 半角、大小写都不影响）；
2. **语义**：正文片段，按意思找。只输入关键词时不看正文。

检索模式可切换：

| 模式 | 什么时候用 |
|------|-----------|
| 混合 · 关键词 + 语义（默认） | 日常使用；语义服务慢或不可用时会自动只回关键词结果，并给一行提示 |
| 仅关键词 | 想快速、稳定地按标题 / 描述 / 分类 / 标签找 |
| 仅语义 | 只想按正文意思找 |

**检索语法**（写在检索词里即可）：

| 写法 | 作用 |
|------|------|
| `复盘 模板` | 两个词都要命中 |
| `"每周回顾"` | 引号里当整体短语 |
| `标题:复盘` / `title:复盘` | 只在标题里找（还有 `描述:` / `desc:`、`分类:` / `category:`、`标签:` / `tag:`） |
| `-模板` / `NOT 模板` | 排除含这个词的对象，可带字段 |
| `OR`、括号 | 不支持，会提示改成两次检索或加筛选 |

「相似度阈值」只影响语义结果，不影响关键词命中——调高它不会让标题命中的条目消失。结果超过 500 条会提示收窄范围。

### 第 6 步：看知识图谱

1. 左侧点「知识图谱」；
2. 在**左上角那张玻璃卡**里点「同步内容」（实体详情在右上角，两张卡同一水平线，中间是整幅星图）；
3. 等抽取完成（云端模型下，20–30 块的长文约 2–3 分钟；本机 CPU 上会慢得多），刷新后左侧出现实体列表；
4. 点实体看它的关系图；先点一个实体，再按住 `Shift` 单击另一个实体，就能看到两者之间的路径（顶部提示条会写「A → B · N 跳」，没有通路也会写明）；
5. 右上角详情卡底部有「相关文档」，展开后列出这个实体来源的本账号文章，点标题直接跳到文章详情；
6. 星图最下方居中的「问图谱」搜索框可以直接提问，回答由你在「设置 → 大模型」里绑定的大模型生成，卡片底部写明模型名，并列出引用的文档。

> 图谱是手动同步的：新上传或修改内容后，要再点一次同步。图谱只显示属于你账号的内容。

抽取失败时，失败面板和进度区会多一行**模型诊断**：它当场试连一次你配置的模型服务，告诉你「连不上 / 密钥被拒 / 限流 / 超时 / 能连但抽取仍失败」。看到「能连但抽取仍失败」就展开失败项看原因再点「重新抽取」；看到「连不上」先修模型配置（见 4.3），修好后再重抽。

## 3. 日常怎么用

### 3.1 收集资料

新建「资产」，先放**外库**；上传原文或写说明。不用一开始就分类得很整齐，标题写清楚以后好搜。

### 3.2 资产怎么进内库（AI 打分 + 人工复核）

外库资产进内库只有两条路，没有第三条：

1. 打开这条资产，在「AI 评分」卡点「**开始打分**」，等模型给出六个维度的分数与理由；
2. **≥ 75 分**：自动进入内库，并立刻完成五维价值评估、给出 S / A / B / C 等级；
3. **60–74 分**：进入「待人工复核」。卡片上会出现「通过」「拒绝」——「通过」就是入库并评估，「拒绝」则留在外库；
4. **< 60 分**：标为低价值，留在外库观察或清理。

要快速找待复核的资产，在工作台筛选里把「复核状态」选成「待复核」（或直接打开详情页里的「去复核」链接）。

> 「迁移到内库」对资产已经关闭：入库必须经过打分或复核，不能手动改库别。内库资产可以点「重新评估」刷新等级，也可以主动降到外库。

> **新建时选内库**：新建对话框里「内库」默认是灰的。确实要建一条直接进内库的资产（例如整理一张已经写好的清单），勾选「我知道这会跳过外库打分与复核」才能选——这条不经过打分，但建好后会立刻做五维评估、同样带 S/A/B/C 等级。

### 3.3 把想法推进成作品（已发布 → 已实践）

1. 新建「作品」，选分类，从**草稿**开始（作品固定在外库）；
2. 在详情页上传主内容；
3. 每完成一个阶段，在列表行点右侧的阶段按钮：草稿 → 已完成 → 已发布；只能逐级前进，不能跳级，也不会自动回退；
4. 作品到「已发布」后，按钮变成「**标记已实践**」。点它，可以顺手记录这次实践的数据反馈（全部选填）：
   - 平台（例如小红书、公众号）；
   - 浏览量；
   - 跳出率；
   - 反馈摘要。
5. 确认后，系统在**同一次操作里**完成三件事：创建一条内库资产（来源标为「实践沉淀」，并指回原作品）、立即做五维评估给出等级、把作品状态改成「已实践」。任何一步失败都会整体回滚，不会出现「已实践但没有资产」。

> **已发布 ≠ 已实践**：发布只表示内容上线了；「已实践」必须由你结合真实数据看过效果后手动确认。作品标记已实践后仍留外库，正文照常能检索、预览、进图谱。

### 3.4 编辑、归档、删除

点内容右侧「更多操作」展开：

| 操作 | 效果 | 能否撤销 |
|------|------|----------|
| 编辑 | 改标题、描述、分类、标签、优先级 | 可以再改 |
| 归档 | 从工作台移走，不占地方 | 可以「取消归档」 |
| 删除 | 从工作台移除 | **不能恢复**，删除前会二次确认 |

已归档的作品不能再推进阶段；取消归档后可以继续。

### 3.5 筛选与查找

工作台工具条支持：关键字（标题或描述）、类型（全部 / 资产 / 作品）、库别、状态、**复核状态**（待复核 / 低价值 / 已通过）、**价值等级**（S / A / B / C）、标签、排序，以及「在用 / 已归档」切换。**这些条件全部是平铺按钮，不用先展开下拉再选**——每个条件一行，选项一眼看全，点一下即生效。所有条件都会写进地址栏，刷新或后退不会丢。

**类型只有一个入口**：`全部 | 资产 | 作品` 这一行就是类型筛选，原来的「类型」下拉和顶部那条快捷胶囊做的是同一件事，已经合并，不会出现两个地方选类型、互相打架。内库、外库各自生效，与库别条件可以叠加。

首页「本周新增」这类指标点进来会带上「近 7 天」条件，在列表上方能看到这颗胶囊，点 × 单独去掉。

**目录列太窄 / 详情太宽时**：把目录与详情之间的分隔条左右拖，目录列随之变宽或变窄（300–560 像素），详情区自动让位。松手后宽度会记住，刷新还在；双击分隔条回到默认宽度，选中分隔条后也能用 ← / → 微调。窗口太窄时分隔条会隐藏，避免挤坏布局。

### 3.6 批量处理

列表每行左侧有方框，顶部批量条里也有「全选」；勾选后三个按钮才会亮起：

| 动作 | 效果 |
|------|------|
| 批量归档 | 选中的内容移入「已归档」，之后可以逐条取消归档 |
| 批量导出 | 下载一份 Markdown：每项含标题、归属、阶段、分类、标签、时间与说明；纯文本正文会一起带出，PDF 等附件只列文件名 |
| 批量删除 | 二次确认后从工作台移除，**不能恢复** |
| 批量重评 | 只对**内库资产**生效：勾选后重评选中的那些；一条都没勾时，重评当前 **C 级**与**模型兜底评估**的资产（专治「模型挂了被判 C」）。逐条独立，一条失败不影响其余；结果会写明成功几条、失败几条 |

批量操作只作用于当前勾选的条目，不会动到筛选范围外的内容；刷新页面或切换目录后勾选会清空。批量重评会真实调用模型，一次最多 50 条。

### 3.7 快速预览内容

点列表里的**标题**会直接弹出预览，不用先进详情：PDF 与图片在弹窗里直接看，Markdown 按排版显示，纯文本原样显示，其它格式给下载按钮。弹窗里可以切换同一对象的其它附件；内容还在解析或解析失败时，会写明状态和原因。

**点标题以外的地方进详情**：列表一整行都是通往详情页的入口——点标题左边或右边的空白、时间、标签，都会直接进右栏详情，筛选条件不变。「全部内容」和「作品目录」两个列表的规矩一样：**点名称看预览，点其它位置看详情**。

关闭预览：右上角关闭按钮、按 Esc、或用浏览器「后退」。关掉后光标回到刚才点的标题。想跳过预览直接进详情，除了点标题以外的区域，也可以按住 ⌘（Mac）/ Ctrl（Windows）点标题，或点弹窗右上角的「打开详情」。手机上面预览占满整屏。

### 3.8 AI 提炼与价值等级怎么看

**从草稿提炼资产**：只有**外库作品的草稿**才有「AI 提炼」按钮。点一下，模型从这篇草稿里提炼出**几条可独立理解的知识单元**（通常 3–5 条；正文不够时可能更少，但不会少于 1 条）放进外库，并逐条打分。草稿本身不受影响（仍是草稿）。同一篇草稿只提炼一次：再点会提示「已经提炼过」，并告诉你已有那几条资产在哪——想重新提炼，先把上次生成的候选资产删掉。

提炼有固定模板，所以不会再把一句话碎片当成资产：每条要有标题、60–120 字的摘要、适用场景、2–4 条要点，以及一段**从你正文里逐字摘出来的原文**（100–300 字）。不满足模板的候选会被丢掉，不会入库也不要你手动删。

**AI 综合分（外库资产）**——六个维度各自 0–100 分，按权重加权：

| 维度 | 权重 | 它看什么 |
|------|------|----------|
| 内容完整度与结构清晰度 | 20% | 有没有清楚的问题—方法—结论，关键步骤是否齐全 |
| 洞察深度 / 非显而易见性 | 25% | 是不是常识复述，有没有个人视角或反直觉判断 |
| 可操作性 / 可落地性 | 20% | 有没有具体步骤、检查清单、判断标准 |
| 与已有内库资产的关联与互补性 | 15% | 和现有高价值资产是补充、升级还是重复 |
| 时效性与长期价值潜力 | 10% | 是否强依赖当下热点或某个工具版本 |
| 来源可信度与验证痕迹 | 10% | 来源质量、有无数据支撑、是否已有实践标记 |

结论只有三种：**≥ 75 自动进内库**、**60–74 待人工复核**、**< 60 低价值留外库**。资产头上的徽标就是当前结论（未打分 / 待人工复核 / 低价值 / 已通过 / 已拒绝）；点开卡片能看到每一维的分数和一句理由，复核时不用猜。

**价值等级（内库资产）**——五个维度各 1–5 分：实践验证强度、复用频率 / 复利潜力、可迁移性、独特性 / 稀缺性、时效性 / 衰减速度。综合表现对应四级：

| 等级 | 含义 |
|------|------|
| **S** | 核心资产 · 高验证、高复用、高可迁移 |
| **A** | 重要资产 · 有明确验证，复用价值较好 |
| **B** | 一般资产 · 已进入内库，价值中等 |
| **C** | 观察资产 · 价值较低，考虑降级或归档 |

**等级不是终身制**，但也不会自己乱跳：

- **重新评估**：详情页点「重新评估」立刻重算（模型失败会明确报错，不会悄悄把好资产判成 C）。
- **使用记录**：在资产详情页停留 8 秒以上、点「查看原文」、复制正文、引用到新作品，各算一次「有效调用」；同一个动作一小时内重复只算一次。详情页能看到「使用 N 次 · 最近 …」。
- **评估历史**：详情页的时间线列出每一次变化（什么时候、从哪一级到哪一级、为什么），例如「93 天未使用…复用维度降至 1 分，B → C」。
- **锁定等级**：重要资产可以点「锁定等级」，锁住之后自动升降级不会再动它，徽标会标「已锁定」。解锁随时可以点。
- **自动升降级看的是近 30 天的调用与闲置天数**：近 30 天用得多的会升一级，长时间不用的会降一级，一次最多动一级、S 封顶、C 兜底。目前**没有每日定时任务**——需要时手动触发一轮复核，同一资产 24 小时内只会被自动调整一次。

**正文快照**：内库资产会带一份沉淀时的正文开头（前 2000 字）。作品以后被大改或删掉，资产仍能说明自己当初是从什么内容来的；要看完整原文就点「查看原文」回原作品。

### 4.1 系统管理（仅管理员）

左侧栏点「系统管理」进入。页面三块：

| 区块 | 看什么 |
|------|--------|
| 依赖服务 | RAGFlow / LightRAG / Logto 是否在线（绿点在线、红点不可用），不可用时页面顶部也有提示 |
| 存储与队列 | 数据库文件大小、对象与内容引用数、待投递 / 运行中 / 失败的任务数 |
| 用户与归属 | 每个账号有多少资产、多少作品；用来核对自己或他人的数据是否在库里 |

右上角两个按钮：「立即同步队列」把还没投递的内容推到 RAGFlow，「推进解析状态」立刻刷新解析进度。平时不用点——后台每 30 秒自己跑一轮，这两个按钮只在排障或刚上传完想马上看到状态时用。

目录「系统」下还有一个「大模型」入口，用来换图谱抽取与问答用的大模型，详见 4.3。

> 非管理员访问 `/admin` 会看到「当前账号没有管理员权限」的说明页，属正常。

### 4.2 分类与标签（词表）

分类和标签现在是**全站共用的一份词表**：改一次名称，新建、编辑、详情、列表、导出、筛选同时变化，不会再出现「这页改了那页没改」。分类与原来的「作品形态」是同一个东西，现在只有「分类」一个名字。

**日常使用（所有人都可以）**：

| 要做的事 | 在哪里 | 规则 |
|----------|--------|------|
| 给作品选分类 | 新建作品时，标题下面的「分类」区 | 单选 chips，只列出「启用中」的分类；**必须选一个，不默认选中**，避免把作品误放进第一个分类 |
| 给资产选分类 | 新建资产时 | 同样的 chips，另有「不选」；资产可以没有分类，编辑时也能补选或清空 |
| 换分类 | 详情页「更多操作」→「编辑」 | 与新建完全相同的控件；作品不能清空分类 |
| 过滤候选 | 分类 / 标签区上方的输入框 | 输入关键字只过滤下方 chips，**不会创建**；回车只有在名称完全一致时才会选中 |
| 新建词表里还没有的分类 / 标签 | 选区右侧「＋ 自定义」 | 弹出小窗口只填名称，保存后立即选中；分类 12 字以内、标签 20 字以内；同名的启用项直接复用，停用的同名分类会提示「已停用」，不会自动复活 |
| 给内容加标签 | 新建面板与「编辑」弹窗里的「标签」区 | 多选 chips，可点选或「＋ 自定义」；**每个内容最多 10 个，单个标签不超过 20 字**；重复的（包括全角、大小写不同，如 `ＴＯＯＬ` 和 `tool`）会自动合并成一个 |

**管理词表（仅管理员）**

入口在第二列目录的最下方：「管理」分组里有「**管理分类**」「**管理标签**」两项，括号里分别是启用分类数和标签总数。工作台、内容检索、知识图谱、系统管理四个页面的目录底部都有这一组，从哪个页面进都一样；普通账号看不到它。

**管理分类**（`/admin/vocabulary/categories`）

| 操作 | 怎么做 | 规则 |
|------|--------|------|
| 新增 | 顶部输入名称 → 「新增分类」 | 名称 12 字以内；同名分类直接复用（提示已存在，不建重复项）；内部标识自动生成（如「Podcast Show」→ `podcast-show`，纯中文名生成 `c-` 加一串字符），**创建后不可改**；启用分类最多 30 个 |
| 改名 | 行内「重命名」→ 输入 → 保存或回车 | 全站立即生效。对象存的是内部标识，改名不碰任何内容数据 |
| 排序 | 该行的 ↑ / ↓ | 决定新建 / 编辑面板里的先后顺序 |
| 停用 | 「停用」→ 确认 | 停用后不再出现在新建 / 编辑面板里，已有内容照常显示；随时可以「启用」；「未分类」不能停用，且至少要保留一个启用分类 |
| 删除 | 「删除」→ 确认 | **不可撤销**，只是暂时不用请选「停用」；内置分类不能删，只能改名或停用；有内容在用时，弹窗会让你先选「迁移到」哪个分类，那批内容的分类被改写并重新排队同步，然后才删除 |

**管理标签**（`/admin/vocabulary/tags`）

| 操作 | 怎么做 | 规则 |
|------|--------|------|
| 新增 | 顶部输入名称 → 「新增标签」 | 20 字以内；同名标签（忽略全角半角、大小写、首尾空格）直接复用，不会建出重复项 |
| 查找 | 搜索框 + 「排序」（按使用次数 / 按名称） | 只影响列表显示顺序，不改变标签本身的顺序 |
| 改名 | 行内「重命名」→ 保存或回车 | 全站立即生效，用到它的内容一起更新；改成和已有标签同名会提示冲突，这种情况用「合并」 |
| 合并 | 「合并」→ 选目标标签 → 确认 | 源标签消失，关联整体转到目标标签，重复的自动去重，内容本身不动 |
| 删除 | 「删除」→ 确认 | 没被使用时直接删除；还在用时有两个选择：**合并到另一个标签**，或二次确认后**从所有内容上一并移除**（内容不删，只是不再带这个标签，不可撤销） |

> 标签总数超过 500 时不会拦截新增，接口会在响应里带一条「建议合并同义标签」的提示；管理页目前不显示这条提示，可以自己按使用次数排序，把低频的同义词合并掉。

> 普通账号也能选分类、在新建 / 编辑时直接输入新标签（保存内容时自动建进词表），但改名、排序、停用、删除、迁移、合并这些维护动作只有管理员能做；手动输入这两个地址只会看到「没有访问权限」。管理与接口的对应关系见 [06_API.md](06_API.md) 第 6 节。

### 4.3 大模型配置（仅管理员）

左侧栏「系统管理」下面的「大模型」进入（地址 `/admin/llm`）。这里改的是**知识图谱抽取和问答**用的大模型，不影响检索与文件解析。

1. **选供应商**：OpenAI、DeepSeek、通义千问、自定义（任何 OpenAI 兼容接口）或本机 Ollama。
2. **填三项**：接口地址、模型名、API Key。API Key 只显示后四位，保存后不再回显；**输入框留空表示沿用已保存的那把**，只有换供应商才必须重填。
3. **先点「测试连接」**：它会真的向供应商发一个很短的请求。成功再保存，失败会写明是地址、密钥还是模型名的问题。
4. **点「保存」**只记下配置，不影响正在运行的服务。要让配置真正生效，再点「应用并重启 LightRAG」——服务会重启 10–30 秒，期间图谱打不开，正在抽取的内容会中断，失败会自动恢复成原来的配置。
5. 页面顶部会说明「已保存」和「运行中」是否一致；不一致时有一条黄色提示，点「去应用」即可。

> 本机 Ollama 的 `deepseek-r1:7b` 在纯 CPU 上大约每秒 7 个字，长文章常常 5 分钟内抽不完而失败。想让图谱真正有内容，建议换成云端模型——当前已使用 DeepSeek（`deepseek-chat`）。
>
> 点「应用并重启」后请以**页面顶部「运行中」的模型名**为准确认是否真的换了。如果提示成功但抽取仍然失败，先看图谱页的「模型诊断」那一行。

## 5. 常见问题

### 打不开页面 / 图谱说「服务没有响应」

本机依赖没有全部启动。在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\autostart.ps1 -Check
```

有 `down` 就再运行一次不带 `-Check` 的命令拉起，等十几秒刷新。需要 `Docker Desktop` 处于运行状态。

### 登录后报 500，或一直回到首页

Logto 没启动，或回调地址配置不对。先确认 `http://localhost:3001/api/status` 返回 204，再重试登录；仍失败见 [08_RUN_LOG.md](08_RUN_LOG.md) 第 2 节。

### 检索不到刚上传的内容

按顺序排查：

1. 只输了 1 个字——关键词检索要求至少 2 个字；
2. 想找的是正文里的词——关键词只看标题、描述、分类、标签，正文要靠语义层；换成「混合」或「仅语义」模式再试；
3. 内容还在「解析中」——等几十秒；
4. 相似度阈值调得太高——降到 0.2 或更低（只影响语义结果）；
5. 限定了库别——改成「全部」；
6. 内容已归档——归档内容默认不参与检索；
7. RAGFlow 没启动——关键词结果仍然可用，但正文语义检索会降级。

### 检索时提示「不支持 OR」
检索词里不能写 `OR` 或用括号分组。要么分两次检索，要么用一个词加上「分类 / 标签」筛选来收窄范围。排除用 `-`，短语用双引号。

### 上传失败

多为 RAGFlow 未启动或未配置。先确认 `http://localhost:9380/v1/system/version` 有响应，再重试。

### 图谱是空的

按顺序看：

1. **还没点「同步内容到图谱」**——图谱不是上传后自动生成的，要在图谱页手动点一次同步。
2. **抽取还在跑**——本机 CPU 较慢，几分钟到十几分钟都正常，图谱页会显示进度。
3. **抽取失败了**——图谱页的提示条会写「N 个失败」，展开每一项能看到原因：超时、连不上服务、密钥不对、额度不够等。最常见的是超时，说明本机模型太慢，去「系统 → 大模型」换个云端模型，再回来点「重新抽取」。
4. **内容还没解析成功**——图谱只取解析成功的主内容，先在工作台把那条内容的解析跑完。

如果提示条写着「抽取失败：本地模型过慢」，怎么等都不会出现实体，必须换模型后重抽。

### 预览打不开、或者 PDF 一片空白

先看弹窗里写的状态：内容还在解析时要等解析完成；解析失败会写明原因（超时、格式不支持、文件为空）。如果状态正常但 PDF 空白，多半是文件本身只有扫描图片或浏览器不支持内嵌显示——点弹窗里的「下载」用本机软件打开即可。Markdown 或纯文本显示不全时，超过 512 KB 的部分只预览开头，完整内容请在详情页下载。

### 「已实践」按钮不见了

只有**已发布**的作品才有这个按钮：还在草稿 / 已完成时先逐级推进；已经标记过已实践的作品，原位置会换成「已实践，内容已沉淀为内库资产」的说明。作品处于归档状态时，先「取消归档」再操作。

### 数据存在哪里

业务数据在本机 SQLite（`data/app.db`），原文在 RAGFlow 的统一内容库（默认 `pakp-content`）。删除对象是软删除，原文不会立刻从内容库消失。

### 怎么退出

左侧栏最底部是当前账号（头像、名字、邮箱），下面就是「**退出登录**」按钮，点一下即退出。开发模式（固定本地身份）下这一行显示「本地身份，无需登录」，没有退出按钮，属正常。

## 6. 建议的第一次练习

照着做一遍，基本就熟悉了：

1. 新建资产「读书笔记 · 深度工作」，放**外库**；
2. 上传一段 Markdown 或 txt 原文；
3. 等「已解析」后，到「内容检索」搜一个原文里的概念；
4. 新建作品「如何搭建个人知识系统」，分类选**文章**，自动放在**外库**；
5. 在列表里把它从「草稿」推进到「已完成」→「已发布」；
6. 在「已发布」时点「标记已实践」，随手填个浏览量，确认——右侧会多出一条带等级的内库资产；
7. 回到那条读书笔记，点「开始打分」：≥75 自动进内库，60–74 就在复核里点「通过」；
8. 到「知识图谱」点一次同步，等抽取完成后点开一个实体看看。

## 7. 术语表

| 词 | 含义 |
|----|------|
| 资产 | 资料、笔记与参考，以及作品实践后沉淀的成果；没有推进阶段，内库资产带价值等级 |
| 作品 | 要完成并交付的内容，四阶段推进；只存在于外库 |
| 草稿 / 已完成 / 已发布 / 已实践 | 作品的四个阶段，只能逐级前进；「已实践」是终点，由你手动确认，确认时自动沉淀出内库资产 |
| 分类 | 作品的类型（文章、课程……）。内置 7 种，可自定义；停用的分类不再出现在新建 / 编辑面板；资产也可以选分类，但非必填 |
| 标签 | 横跨多种内容的小标记，全站共用一份；每个内容最多 10 个，单个不超过 20 字 |
| 内库 / 外库 | 长期复用 / 收集的输入。内库只有资产，且必带价值等级 |
| AI 综合分 | 外库资产的六维加权总分（0–100），决定它自动进内库、待复核还是留外库 |
| 价值等级 | 内库资产按五个维度评出的 S / A / B / C |
| 有效调用 | 在资产详情停留 8 秒以上、查看原文、复制正文、引用到新作品；同一动作一小时内只算一次，是自动升降级的依据 |
| 评估历史 | 这条资产每一次等级变化的记录：时间、从哪级到哪级、原因 |
| 锁定等级 | 把某个内库资产的等级钉住，自动升降级不再改它；手动重评仍可改 |
| AI 提炼 | 从外库作品的草稿里生成候选资产，产物进外库并自动打分 |
| 实践沉淀 | 作品标记「已实践」时自动生成的那条内库资产（来源显示为「实践沉淀」） |
| 主内容 | 用于检索和进图谱的正文；同类型再传会替换 |
| 附件 | 挂在对象下的补充文件，不参与替换 |
| 解析 | 内容库把原文切成可检索片段，通常几十秒 |
| 同步 | 把对象正文送进知识图谱抽实体和关系，手动触发 |
| 归档 | 移出工作台但保留数据，可恢复 |
| 删除 | 从工作台移除，不可恢复 |
