# AI 文档维护指令

你在本项目中修改代码或完成任务后，必须按以下规则更新文档，以保持方向稳定：

1. **方向锚点不可随意改**
   - 00_SCOPE.md 和 03_DECISIONS.md 的已有决策，除非用户明确要求变更，否则不得修改。
   - 如需变更，必须新增 ADR 并说明原因。

2. **每次完成有意义的工作后**
   - 更新 02_PHASES.md 的「当前状态」「已完成」「下一步行动」
   - 在 05_CHANGELOG.md 追加一条简洁记录（日期 + 做了什么）

3. **实现集成相关功能时**
   - 把真实接口、端口、环境变量、调用方式写入 04_INTEGRATION.md
   - 禁止编造未实现的接口

4. **架构有实质变化时**
   - 同步更新 01_ARCHITECTURE.md
   - 必要时新增 ADR

5. **输出风格**
   - 简洁、可执行、用表格或列表
   - 不删除历史决策，只追加或标记状态变更
