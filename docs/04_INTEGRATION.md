>
> 当前环境：本机 Docker / WSL 未就绪，本轮未启动或连接任何外部服务。

## 填写规则

1. 服务启动并实际访问后，才填写版本、Base URL、端口与控制台地址。
2. 真实 API 调用验证后，才填写接口路径、请求/响应契约与 SDK 用法。
3. 密钥不在本文档记录；只记录经代码验证的环境变量名称。
4. 应用侧设计草案统一放在 `docs/drafts/`，不得视为真实集成事实。
